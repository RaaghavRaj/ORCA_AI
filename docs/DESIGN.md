## Visual Language
- Core visual signature: Nautical coordinate reticle ticks and micro-telemetry badges with hairline bathymetric contour lines and radar scanline accents.
- Material & depth: Layered deep ocean slate cards with subtle luminous borders (#334155 to #0284C7 on focus), dark matte telemetry glass panels.
- Containers & buttons: Compact modular telemetry blocks with crisp 1px borders, monospace coordinate readouts, tactile buttons with micro-glow on active states.
- Layout rhythm: High-density multi-agent execution pipeline and telemetry controls flanking a prominent geospatial command map.

## Animation
- Entrance: Telemetry counter and agent status pop-in (200ms ease-out)
- Interaction: Tactical hover brightening border lines with 150ms transition, active hazard radar ping ripple
- Transition: Smooth layer and filter toggle cross-fade (150ms ease-in-out)

## Forbidden
- No bright flat primary/accent color fills across large background or hero containers
- No decorative generic emoji in navigation, telemetry, or system status headers
- No distracting floating background particles or looping decorative animations

## Additional Notes
- All user-visible copy follows English as the base UI with full multilingual toggle and detection for 9 Indian regional languages (Hindi, Tamil, Telugu, Malayalam, Bengali, Gujarati, Marathi, Kannada, English)
